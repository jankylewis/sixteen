# Vision

Bring the full AgentFarm capability set to a public audience: agent coordination, development workflows, reusable skills, quality engineering, and supporting tools.

## Public boundary

Every contribution must be independently understandable and usable outside its original environment. Exclude organization-specific business logic, terminology, domain knowledge, project references, customer data, internal infrastructure details, and operational records.

Write public documentation and examples from scratch using generic or synthetic content. Review code, fixtures, configuration, metadata, and Git history before importing any existing component. Renaming identifiers alone does not establish that material is suitable for publication.

Never commit secrets, credentials, private URLs, local environment files, raw session transcripts, or production data. Preserve applicable licenses and verify publication rights before importing third-party code.

## Delivery

Begin with the directory scaffold. Introduce capabilities incrementally, with public documentation and evidence for each delivered behavior. The initial scaffold does not claim migration completeness or provider parity.
